# jankenpo-flutter

Aplicativo simples de pedra, papel e tesoura feito em Flutter.

Para executar, use o comando do framework:

> flutter run

É preciso ter instalado, para rodar com Flutter:

- Flutter
- Android Studio
- Java

## Ícone do aplicativo

Gerado com o pacote de ícones na versão indicada.

O ícone do lançador fica na pasta de ícones do projeto.

## Ícones das opções do jogo

Os ícones estão no arquivo de dados das opções.
